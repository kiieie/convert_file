# 도구 페이지 UI 단순화 설계 (파일럿)

날짜: 2026-07-03
상태: 승인 대기
범위: 파일럿 3개 도구 (영어판) — `tools/webp-convert.html`, `tools/jpg-png.html`, `tools/compress.html`

## 배경 및 목표

현재 도구 페이지는 2컬럼 레이아웃에 모든 옵션(품질 슬라이더, 배경색, 변환 버튼 3~4개)이 항상 노출되어 복잡하다. 목표:

1. 기본 흐름을 "업로드 → 변환 버튼 1개 클릭 → 다운로드"로 단순화
2. 고급 옵션은 접힘(`<details>`) 상태로 숨기고 필요할 때만 펼침
3. 스마트 기본값으로 설정 없이도 올바른 결과 제공
4. 파일럿에서 패턴 확정 후, 별도 단계에서 나머지 21개 도구 + 번역본(ko/es/zh, 72개 파일)으로 롤아웃

비목표(이번 범위 제외):
- 신규 유틸리티 추가 (별도 스펙)
- 번역본 페이지 수정
- 빌드/템플릿 시스템 도입
- 랜딩(index.html), 블로그, XP 테마 변경

## 접근법 결정

채택: **공통 CSS 패턴 + 페이지별 마크업 수정** (접근법 A)

- 기각: 템플릿/빌드 시스템 도입 — 정적 호스팅 아키텍처 대전환, 이번 목표 대비 과함
- 기각: 런타임 JS 재배치 — FOUC, 접근성 저하, 취약

## 페이지 레이아웃 패턴

2컬럼(`modern-tool-grid`) → 단일 컬럼 세로 흐름. 위에서 아래로:

```
[헤더: 제목/설명]              — 유지
[광고 슬롯]                    — 유지
[업로드 드롭존]                — 유지
[미리보기: 원본 | 결과]        — 유지
[통계바]                       — 유지 (변환 후 표시)
[포맷 세그먼트 토글]           — 포맷 선택 필요 도구만, 항상 노출
[✨ 변환하기]                  — 큰 CTA 1개, 업로드 전 disabled
[⬇ 다운로드]                  — 변환 성공 후 표시, 초록 강조
[▸ 고급 설정]                  — <details> 접힘, 기존 옵션 카드 전부 이동
[하단 SEO 안내문/FAQ]          — 유지
```

## 공통 컴포넌트

### CSS (`css/tools.css`에 추가, 기존 클래스 삭제 없음)

| 클래스 | 역할 |
|---|---|
| `.tool-flow` | 단일 컬럼 세로 스택, `max-width: 720px`, 가운데 정렬, gap 12px |
| `.segment-toggle` | 라디오 그룹 기반 포맷 선택. 숨긴 `<input type="radio">` + 라벨 버튼. 선택 항목 파란 강조 |
| `.btn-convert-hero` | 큰 변환 CTA. 전체 폭, 높이 48px 이상, `--blue-600` 배경 |
| `.advanced-settings` | `<details>`/`<summary>` 스타일. summary에 ▸ 아이콘, 펼침 시 기존 `.modern-card` 그대로 렌더 |

기존 클래스를 삭제하지 않으므로 미적용 페이지는 영향 없음.

### JS

- 신규 코어 모듈 없음. 세그먼트 토글은 순수 HTML radio + CSS로 동작.
- 각 도구의 인라인/개별 JS에 스마트 기본값 로직 추가.
- 캐시버스팅: 수정된 페이지의 스크립트 참조 `?v=` 파라미터 증가 (`_headers`의 immutable 캐시 정책 대응).

## 스마트 기본값 규칙

1. 업로드 시 기존 매직바이트 검사(`js/core/file-utils.js`)로 입력 포맷 감지.
2. 출력 포맷 자동 선택:
   - WebP 입력 → JPG
   - JPG/PNG 입력 → WebP
   - 그 외(GIF/BMP) → PNG
3. 품질 기본값 85%.
4. 배경색 카드: "JPG 출력 선택 + 투명 채널 있는 입력"일 때만 고급 설정 내부에 표시. 그 외 숨김.
5. 변환 완료 후 포맷 토글 또는 고급 설정 변경 시:
   - 상태 메시지 "설정 변경됨 — 다시 변환하세요" 표시
   - 다운로드 버튼 흐림 처리(disabled + opacity), 재변환 시 복구

## 파일럿 페이지별 적용

### tools/webp-convert.html
- 버튼 3개(To WebP / To JPG / To PNG) 제거 → 세그먼트 `[WebP | JPG | PNG]` + 변환 버튼 1개
- 품질 슬라이더, 배경색 카드 → 고급 설정으로 이동
- Image Info 카드 → 고급 설정으로 이동 (통계바가 핵심 정보 대체)

### tools/jpg-png.html
- 동일 패턴. 세그먼트 `[JPG | PNG | WebP]`
- 기존 옵션 카드 전부 고급 설정으로 이동

### tools/compress.html
- 포맷 유지 압축이므로 세그먼트 없음. 변환(압축) 버튼 1개만
- 품질/목표 크기 설정 → 고급 설정으로 이동

## 에러 처리

- 기존 `js/core/ui-components.js` 모달 에러 다이얼로그 그대로 사용.
- 지원하지 않는 파일 업로드 시 기존 매직바이트 검사 경로의 에러 표시 유지.
- 변환 실패 시 상태 메시지 영역에 에러 표시, 다운로드 버튼 비노출 유지.

## 테스트

1. **유닛**: `node test/run-tests.js` 회귀 통과.
2. **E2E** (`test/e2e.test.js`, Playwright):
   - 기존 jpg-png 케이스는 새 흐름(세그먼트 선택 → 변환 1버튼)에 맞게 수정.
   - 파일럿 3개 각각: 업로드 → 자동 선택 포맷 검증 → 변환 → 다운로드 파일명 패턴 검증.
   - compress: 업로드 → 변환 → 출력 크기 < 원본 크기 검증.
3. **수동 확인**: 모바일 뷰포트(375px)에서 세로 흐름 및 세그먼트 토글 레이아웃 확인.

## 완료 기준

- 고급 설정 접힘 기본, 펼치면 기존 옵션 전부 접근 가능.
