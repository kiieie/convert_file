# 한국어 도구 가이드 — 운영자 실측 자료 체크리스트

> 대상: `ko/tools/{img-pdf,metadata,compress,heic2jpg,gif-speed}.html`의 `<section class="tool-guide">`
> 목적: AdSense "가치가 별로 없는 콘텐츠" 대응. 직접 해 본 결과(실측 수치·실제 캡처)는 AI가 만든 일반론과 구분되는 가장 강한 근거다.
> 위치: 각 페이지에 `<!-- TODO(운영자 실측): ... -->` 주석으로 표시해 두었다. 이 자리를 아래 자료로 바꾼다.

**원칙: 수치는 반드시 직접 측정한 값만 넣는다.** 추정값이나 만들어 낸 숫자는 넣지 않는다.

| 페이지 | 준비할 자료 | 넣을 형태 |
|---|---|---|
| 사진 PDF로 묶기 (`img-pdf`) | 영수증 사진 10장(원본 합계 용량 기록)을 고화질 95% / 중화질 75% / 저화질 50%로 만든 PDF 용량, 각 PDF를 확대했을 때 글씨가 읽히는지 | 3행 표 + 확대 캡처 1장 |
| 위치정보 삭제 (`metadata`) | 실제 휴대폰 사진 1장의 제거 전/후 정보 화면 캡처 (**GPS 좌표는 가리기**), 제거 전후 파일 용량 | 캡처 2장 + 용량 한 줄 |
| 용량 줄이기 (`compress`) | 같은 휴대폰 사진을 100 / 80 / 60 / 40%로 압축한 용량, 얼굴이나 글자 부분 확대 비교 | 4행 표 + 확대 비교 캡처 |
| HEIC → JPG (`heic2jpg`) | 아이폰 HEIC 사진 3장을 품질 92 / 80으로 변환한 용량 (원본 HEIC 대비) | 표 |
| GIF 속도 (`gif-speed`) | 같은 GIF를 0.5배 / 2배 / 역재생으로 바꾼 결과, 각각의 재생 시간과 용량 | 표 + 결과 GIF 또는 캡처 |

## 이미지 넣는 방법

1. 캡처는 가로 1200px 이하 WebP 또는 JPG로 저장한다 (이 사이트의 [용량 줄이기](/ko/tools/compress)를 써도 된다).
2. `assets/guide/<도구이름>-<설명>.webp` 경로에 넣는다.
3. 해당 TODO 주석 자리에 넣는다:
   ```html
   <figure>
       <img src="/assets/guide/compress-quality-compare.webp" alt="같은 사진을 화질 100/80/60/40%로 압축한 결과 비교" width="1200" height="600" loading="lazy">
       <figcaption>직접 찍은 사진(원본 4.2MB)을 화질별로 압축한 결과</figcaption>
   </figure>
   ```
4. `alt`에는 이미지 내용을 구체적으로 쓴다 (검색과 접근성 모두에 도움).
