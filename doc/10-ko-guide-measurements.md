# 한국어 도구 가이드 — 운영자 실측 자료 체크리스트

> 대상: `ko/tools/{img-pdf,metadata,compress,heic2jpg,gif-speed}.html`의 `<section class="tool-guide">`
> 목적: AdSense "가치가 별로 없는 콘텐츠" 대응. 직접 해 본 결과(실측 수치·실제 캡처)는 AI가 만든 일반론과 구분되는 가장 강한 근거다.
> 상태 (2026-10-24): **5개 페이지 모두 실측 완료**. 각 페이지의 "직접 해 봤습니다" 섹션에 표로 들어가 있다.
> 측정 방법: PC Chromium(Playwright)에서 사이트 도구를 그대로 실행해 결과 파일을 저장하고, 용량·픽셀·EXIF·재생 시간을 별도로 검증.
> 샘플: 공개 샘플(ianare/exif-samples, heic2any·libheif 예제, gifuct-js 데모)과 측정용으로 만든 테스트 영수증 이미지. 이미지 자체는 사이트에 올리지 않고 수치만 사용했다.

**원칙: 수치는 반드시 직접 측정한 값만 넣는다.** 추정값이나 만들어 낸 숫자는 넣지 않는다.

## 측정에서 확인된 사실 (가이드에 반영됨)

| 도구 | 확인된 사실 |
|---|---|
| 용량 줄이기 | 100%로 저장하면 원본보다 2배 이상 커짐(+124%, +141%). 80%에서 −54~55% |
| 위치정보 삭제 | GPS·기종·촬영일시 삭제, 픽셀 완전 동일. 세로 사진은 회전 정보가 지워져 가로로 표시됨 |
| HEIC → JPG | 결과가 원본보다 커질 수도(40KB → 194KB) 작아질 수도(701KB → 454KB) 있음 |
| 사진 PDF 묶기 | 영수증은 저화질 50%에서도 글자가 또렷함. 사진 4장 PDF는 95% → 50%에서 약 1/4 |
| GIF 속도 | 느리게는 정확. 빠르게는 프레임당 최소 0.04초 제한으로 4배가 2배와 같아지기도 함. 결과 용량 증가 |

## 운영자가 추가하면 더 좋은 것 (선택)

- 본인이 직접 찍은 사진·영수증으로 한 결과 1~2개와 화면 캡처. "제가 직접 해 보니" 같은 1인칭 경험은 다른 사람이 대신 만들 수 없다.

## 이미지 넣는 방법

1. 캡처는 가로 1200px 이하 WebP 또는 JPG로 저장한다 (이 사이트의 [용량 줄이기](/ko/tools/compress)를 써도 된다).
2. `assets/guide/<도구이름>-<설명>.webp` 경로에 넣는다.
3. 해당 TODO 주석 자리에 넣는다:
   ```html
   <figure>
       <img src="/assets/guide/compress-quality-compare.webp" alt="같은 사진을 화질 100/80/60/40%로 압축한 결과 비교" width="1200" height="600" loading="lazy">
       <figcaption>직접 찍은 사진(원본 4.2MB)을 화질별로 압축한 결과</figcaption>
   </figure>
   ```
4. `alt`에는 이미지 내용을 구체적으로 쓴다 (검색과 접근성 모두에 도움).
