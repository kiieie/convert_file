아이폰 HEIC 사진을 JPG로 바꾸는 방법

아이폰은 기본 설정에서 사진을 HEIC 형식으로 저장합니다. 같은 화질에서 용량이 작다는 장점이 있지만, 윈도우의 일부 프로그램이나 관공서·회사 업로드 페이지에서는 열리지 않거나 첨부가 거부되는 경우가 있습니다.

이 도구는 HEIC 사진을 어디서나 열리는 JPG로 바꿔 줍니다. 변환은 브라우저 안에서 이뤄지고 사진은 서버로 올라가지 않습니다.

사용 방법

  1. 파일 선택을 눌러 HEIC(또는 HEIF) 사진을 고르거나 위 상자에 끌어다 놓습니다. 한 번에 한 장씩 변환합니다.
  2. 품질 슬라이더(50~100, 기본 92)를 정합니다. 높을수록 화질이 좋고 용량이 큽니다.
  3. JPG로 변환하기를 누르면 변환 전후 용량이 표시됩니다.
  4. JPG 다운로드를 눌러 저장합니다.

이럴 때 쓰세요

  • 아이폰 사진을 윈도우 PC로 옮겼는데 열리지 않을 때
  • 업로드 사이트가 JPG·PNG만 받는다고 할 때
  • HEIC 사진을 메일로 보냈더니 상대방이 못 연다고 할 때
  • HEIC 사진을 PDF로 묶거나 다른 편집 도구에 넣기 전에

알아두면 좋은 점

  • 처음부터 JPG로 찍으려면 아이폰 설정 → 카메라 → 포맷에서 "높은 호환성"을 고르세요.
  • PC로 옮길 때 자동으로 바꾸려면 아이폰 설정 → 사진 → "Mac 또는 PC로 전송"을 "자동"으로 두세요.
  • 연속 촬영(버스트) 사진은 첫 번째 장만 변환됩니다. 라이브 포토는 움직이는 부분 없이 정지 사진으로 저장됩니다.
  • 변환은 내 기기의 브라우저가 처리하기 때문에 파일이 크거나 휴대폰이 오래됐다면 몇 초 걸릴 수 있습니다.

내 파일은 안전한가요?

이 페이지에서 고른 파일은 2convert 서버로 전송되지 않습니다. 파일을 읽고 바꾸는 일은 모두 지금 쓰고 있는 브라우저 안에서 이뤄지고, 페이지를 닫으면 작업 내용도 함께 사라집니다.

자주 묻는 질문

변환하면 화질이 떨어지나요?

JPG도 압축 형식이라 아주 미세한 차이는 생길 수 있지만, 기본값 92에서는 눈으로 구분하기 어려운 수준입니다. 더 높은 화질이 필요하면 100으로 올리세요.

여러 장을 한 번에 바꿀 수 있나요?

현재는 한 번에 한 장씩 변환합니다.

사진이 서버로 올라가나요?

아니요. 변환은 브라우저 안에서만 이뤄지고 사진은 어디에도 전송되지 않습니다.

JPG로 바꾼 뒤 용량이 오히려 커졌어요.

정상입니다. HEIC는 JPG보다 압축 효율이 좋은 형식이라 같은 화질이면 JPG 용량이 더 큽니다. 용량을 줄이려면 품질 값을 낮추거나 이미지 압축 도구를 쓰세요.
